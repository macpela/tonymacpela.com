Presence Error

Interactive installation · Azure Kinect · High-Powered Laser

Watch on Vimeo

Presence Error captures a person and projects them back as almost nothing. Azure Kinect tracks the participant. The system keeps the outline and throws that outline forward with a high-powered laser. Tony calls the result a luminous echo: identity stripped to form, motion, and moment. The questions printed on the card are the concept: what remains when presence is only a signal, and where the body ends if the room can draw it. This is an interactive installation and a laser design at the same time. The laser is the screen.

Kinect plus high-powered laser is a safety and a staging problem, and the page names the tools because the sheet names them, not because it publishes a risk assessment. There is no rider here. There is a Vimeo and a still. The artistic claim is the reduction. Holotouch keeps the hands expressive and triggers pictures from signs. Ink Flow borrows a face and gives it back. Presence Error will not keep the face at all. That is why it belongs on the laser page beside Mostly Fine, Thanks and also feels nothing like that play. One beam is a metaphor for coping on a stage. This beam is a display technology for an outline in a room.

Căutarea care i se potrivește este Azure Kinect împreună cu laser design de instalație, nu tăiere industrială și nu un show de club. Conturul este singura identitate permisă. Întrebarea publicată — unde te termini și unde începe camera — este brief-ul. Nu îl lungim cu un scenariu.

Programmers and curators should decide which refusal they want before they write. Signal and outline: this piece. Loaned face: Ink Flow. Assembled statue you can hold: ASCEND. Tony Macpela in Bucharest can talk about all three because he built them. The email should name one.

Presence Error is published as Interactive installation. An interactive audiovisual installation that captures and re-projects the human form in real time. Using Azure Kinect, the installation tracks participants and isolates only their outline —a luminous echo, projected in front of them using a high-powered laser. The result is a raw, minimal version of self: identity stripped down to form, motion, and moment. It invites the audience to question: What remains when your presence is reduced to a signal? Where do you end, and the environment begin?
